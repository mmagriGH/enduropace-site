Version 1.4

Version 1.4 — Race Day Intelligence

Version 1.4 brings EnduroPace’s race-day planning experience together into a more connected workflow, with a redesigned Home, expanded Race Day Planner, deeper Performance Lab integration, and substantial polish throughout the app.

Race Day Planner

  • Expanded race-day planning with pacing, race conditions, hydration, sodium, fueling, transitions, and execution timeline.
  • Connected Performance Lab measurements and saved Sweat Tests to Race Day planning.
  • Added readiness guidance and Next Best Action to help identify incomplete planning inputs.
  • Improved race-plan editing, navigation, persistence, and consistency.

Home

  • Redesigned Home around the next race and current planning state.
  • Added Next Race, target finish, readiness, and Continue Planning presentation.
  • Added Next Best Action for contextual planning guidance.
  • Added Measure → Model → Plan → Execute progress.
  • Added quick access to Performance Lab, Race Day Planner, Training Tools, and Resources.

Performance Lab

  • Improved Run Threshold Pace, Bike FTP, and Swim CSS measurement workflows.
  • Added and refined Sweat Test support for hydration and sodium planning.
  • Improved saved measurement management and Race Day Planner integration.
  • Expanded educational resources for performance and hydration testing.

More, Privacy & Reliability

  • Refined Getting Started, Settings, Help & About, Support, Privacy, and Release Notes.
  • Added clearer unit presentation and Default Activity settings.
  • Added optional anonymous usage analytics, off by default.
  • Improved bottom-navigation spacing, visual consistency, accessibility, and reliability.
  • Continued local-first design with no account required for the current experience.

Version 1.3 — Multisport, Performance Lab & Race Day Planning

EnduroPace 1.3 expanded the app into a broader endurance planning experience for runners, cyclists, swimmers, and multisport athletes.

New

  • Added a complete Swim calculator with distance, time, pace, splits, and saved plans.
  • Added Brick, Duathlon, and Triathlon planning.
  • Added race-distance presets, custom multisport distances, and transition planning.
  • Added complete multisport target finish-time calculations.
  • Added Performance Lab for Run Threshold Pace, Bike FTP, and Swim CSS.
  • Added sport-specific training zones and measurement history.
  • Added Race Day Planner with race details, strategy, transitions, and target finish time.
  • Added a connected Home dashboard and broader navigation structure.

Improved

  • Redesigned Run, Bike, Swim, and multisport calculator interactions.
  • Redesigned navigation around Home, Calculate, Plans, Performance, and More.
  • Improved unit synchronization and distance-conversion precision.
  • Improved validation, persistence, saved-plan reliability, and accessibility.
  • Improved overall visual consistency and sport-specific styling.

Version 1.2 — EnduroPace, Run + Bike Planning

This release expanded the app from a running pace calculator into a broader endurance planning tool.

  • Rebranded the app from RunPace to EnduroPace.
  • Added Bike planning, speed/time/distance calculations, splits, and saved bike plans.
  • Added Run estimated-distance mode from goal time and goal pace.
  • Added cleaner Run and Bike detail sections and sport-specific colors.
  • Improved saved-plan handling and continued privacy-first, account-free use.

Version 1.1 — Run Planning Improvements

This release improved the original running calculator with more planning tools and a cleaner experience.

  • Added run splits, pace zones, race-performance estimates, and same-pace finish estimates.
  • Added saved favorite race plans stored locally on the device.
  • Added Settings, unit management, calculator reset, and saved-plan management.
  • Improved Help & About content, layout, and calculated-result labeling.

Version 1.0 — Initial RunPace Release

This was the first public release of the app.

  • Running pace calculator.
  • Support for 5K, 10K, Half Marathon, Marathon, and custom distances.
  • Miles and kilometers.
  • Calculate pace from distance and target time or finish time from distance and pace.
  • Show calculated speed.
  • Local calculations with no login or account required.

EnduroPace is a planning tool. Actual results may vary based on training, terrain, weather, elevation, equipment, fueling, hydration, fatigue, and race-day conditions.
