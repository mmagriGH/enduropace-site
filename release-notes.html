Latest Release

Version 1.3 — Multisport, Performance Lab & Race Day Planning

EnduroPace 1.3 is the largest update yet, expanding EnduroPace into a complete endurance planning experience for runners, cyclists, swimmers, and multisport athletes.

New

  • Added a complete Swim calculator with distance, time, pace, splits, and saved plans.
  • Added Brick planning.
  • Added Duathlon planning.
  • Added Triathlon planning.
  • Added race-distance presets and custom multisport distances.
  • Added transition planning for multisport events.
  • Added complete multisport target finish-time calculations.
  • Added Performance Lab for Run threshold pace, Bike FTP, and Swim CSS.
  • Added sport-specific training zones.
  • Added Performance Lab measurement history.
  • Added Race Day Planner with race name, location, date, race type, strategy, transitions, and target finish time.
  • Added a connected Home dashboard with Next Race, Quick Start, Performance Anchors, Race Day Strategy, and recent saved plans.

Redesigned

  • Redesigned Run, Bike, and Swim calculators around the new Orbit interaction.
  • Redesigned multisport planning with sport-specific Orbit views.
  • Redesigned the app navigation around Home, Calculate, Plans, Performance, and More.
  • Redesigned Settings, Help & About, Support, Privacy, and Release Notes.
  • Improved saved-plan navigation and access throughout the app.

Improved

  • Improved unit synchronization across Run, Bike, Swim, Brick, Duathlon, and Triathlon.
  • Improved distance-conversion precision using canonical measurements.
  • Improved validation and error handling.
  • Improved persistence and saved-plan reliability.
  • Improved accessibility labels and navigation.
  • Improved calculator state handling and calculated-value promotion.
  • Improved overall visual consistency and sport-specific styling.

Version 1.2 — EnduroPace, Run + Bike Planning

This release expanded the app from a running pace calculator into a broader endurance planning tool.

What’s New

  • Rebranded the app from RunPace to EnduroPace.
  • Added Bike planning.
  • Calculate bike average speed from ride distance and ride time.
  • Calculate estimated ride time from bike distance and average speed.
  • Calculate estimated bike distance from ride time and average speed.
  • Added bike splits.
  • Added same-speed bike finish estimates.
  • Added saved bike plans.
  • Added Run estimated distance mode from goal time and goal pace.
  • Added cleaner Run and Bike detail sections.
  • Added sport-specific colors for Run, Bike, Swim, Brick, and Triathlon.
  • Updated About, Help, and Settings wording for Run and Bike.
  • Improved saved plan handling for calculated distance modes.
  • Continued privacy-first design with no account required.

What’s New

  • Added race performance estimates.
  • Added same-pace finish estimates.
  • Added saved favorite race plans stored locally on the device.
  • Added a Settings screen.
  • Moved unit selection into Settings.
  • Added calculator reset.
  • Added saved plan management.
  • Improved About / Help content.
  • Improved layout and reduced screen clutter.

Version 1.0 — Initial RunPace Release

This was the first public release of the app.

What’s Included

  • Running pace calculator.
  • Support for 5K, 10K, Half Marathon, Marathon, and custom distances.
  • Miles and kilometers.
  • Calculate pace from race distance and goal finish time.
  • Calculate estimated finish time from race distance and goal pace.
  • Show calculated speed.
  • Simple privacy-first design.
  • No login or account required.
  • Calculations performed locally on the device.
EnduroPace is a planning tool. Actual results may vary based on training, terrain, weather, elevation, equipment, fueling, hydration, fatigue, and race-day conditions.
