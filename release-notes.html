Version 1.5

Version 1.5 — EnduroPace Pro & Connected Race Intelligence

Version 1.5 is EnduroPace's first paid release and expands the app from connected race planning into a deeper performance and race-intelligence platform while keeping the core Free experience useful.

EnduroPace Pro

  • Added annual and monthly EnduroPace Pro subscriptions with a 3-day introductory trial when eligible.
  • Added Restore Purchases and Manage Subscription support through Apple StoreKit.
  • Kept the established 1.4 core experience available without Pro.

Apple Intelligence Coach

  • Added Apple Intelligence Coach explanations on supported devices for Pro athletes.
  • Uses EnduroPace deterministic engines as the source of truth and generates natural-language context around those facts.
  • Added deterministic fallback when Apple Intelligence is unavailable or a generated response is not suitable.
  • Extended explanation support across Home, performance, hydration, fueling, and Race Plan History intelligence surfaces.

Apple Health & Connected Athlete Data

  • Added optional read-only Apple Health integration for Pro athletes.
  • Added granular data-use preferences and logical connection controls.
  • Added explicit adoption of supported Apple Health FTP observations into EnduroPace rather than automatic replacement.
  • Preserved source, measurement date, freshness, confidence, and provenance for connected measurements.
  • Added source-aware review so EnduroPace can explain which performance input is currently being used and why.

Advanced Performance Intelligence

  • Expanded Run Threshold Pace, Bike FTP, and Swim CSS history with trend context, source, method, measured date, freshness, confidence, and plan usage.
  • Added richer performance history and actionable next-step guidance for Pro athletes.
  • Improved measurement editing and preservation of canonical history.

Race Weather & Location Intelligence

  • Added verified race-location workflows and stronger disambiguation for ambiguous or misspelled places.
  • Added Apple Weather lookup for supported race dates and locations.
  • Added reviewable weather suggestions without silently replacing athlete-entered race conditions.
  • Added location-aware race hero imagery with sport artwork fallback.
  • Added optional custom race photos stored locally for each race.

Advanced Race Planning

  • Added Race Plan History and meaningful version comparison.
  • Added affected-plan detection when important upstream athlete data changes.
  • Added impact review with explicit Apply, Keep Existing, and Review Later decisions.
  • Added Race Checklist with built-in and custom items.
  • Improved cross-leg fueling, hydration, sodium, readiness, and execution-timeline intelligence.

Fueling, Hydration & Nutrition Strategy

  • Added advanced fueling assessment and race-level carbohydrate requirement context.
  • Added advanced hydration assessment using saved Sweat Test context, freshness, race-condition similarity, and better-match guidance.
  • Added reusable nutrition strategy templates and safer application to compatible Race Day Plans.
  • Kept all recommendation changes explicit and reviewable rather than silently mutating race plans.

Privacy, Reliability & Polish

  • Added App Privacy Manifest declarations for required-reason APIs used by EnduroPace.
  • Expanded in-app privacy disclosures for Apple Health, Apple Weather, Apple Maps imagery, custom photos, subscriptions, and Apple Intelligence.
  • Improved persistence, entitlement startup behavior, async safety, unit consistency, testing, and regression coverage.
  • Optimized curated race hero assets while preserving visual quality.
